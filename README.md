# Proyecto IA Generativa

Este repositorio reúne los ejercicios y actividades de inteligencia artificial generativa. 

## Estructura del proyecto

```text
IA-generativa/
├── IA-s1/
│   ├── IA-reto1.py
│   ├── IA-reto1.jpg
│   └── README.md
├── IA-s2/
│   ├── README.md
│   └── riwi-tres-cupos-borrador.txt
├── IA-s3/
│   ├── promt-entreletras.txt
│   └── url-entreletras.txt
└── README.md
```

## Carpetas

### IA-s1
Carpeta del primer ejercicio. Aquí se encuentran el archivo principal de código (`IA-reto1.py`), una imagen de referencia (`IA-reto1.jpg`) y la documentación de la actividad (`README.md`).

### IA-s2
Carpeta dedicada a la actividad "tres cupos, ocho estudiantes". Incluye la documentación del caso y el archivo generado por la página web que usamos en la actividad práctica de la sesión. (`riwi-tres-cupos-borrador.txt`).

### IA-s3
Carpeta correspondiente al tercer ejercicio del proyecto. el prompt para crear la web (`promt-entreletras.txt`) y la URL de la web (`url-entreletras.txt`).
